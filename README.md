# Moodapp

This is an remote module of an micro-frontend health application. The host is located at https://github.com/neuroconnect26/Host-App 

The host app can be accessed at https://neuroconnect26.github.io/Host-App/
This app can be accessed at https://stacey-gao.github.io/moodapp/

## To run this locally...
Clone the repository and run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4201/`. The application will automatically reload whenever you modify any of the source files.
